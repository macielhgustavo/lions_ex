# lions_ex

Exercícios de Express com TypeScript.

- `exercicio-07`: middleware logger
- `exercicio-08`: UserService
- `exercicio-09`: AppError e middleware global
- `exercicio-10`: CRUD de produtos
- `exercicio-11`: RequestHandler tipado
- `exercicio-12`: UserRepository

Instale as dependências na raiz com `npm install` e inicie um exercício com `npm run dev:07`, por exemplo.
